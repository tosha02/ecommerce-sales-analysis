# E-commerce Sales Analysis


## Project Overview
This project analyzes an e-commerce dataset to understand sales performance, product categories, and customer purchasing behavior.

The goal of the analysis is to identify trends in revenue, product performance, and customer activity.

## Dataset
The dataset contains information about orders, payments, products, and customers.

Main tables used:
- orders
- order_items
- payments
- products

## Analysis Performed

### Revenue Analysis
- Total revenue calculation
- Revenue by month
- Average order value by month

### Product Analysis
- Revenue by product category
- Number of orders by category
- Average price by category

### Customer Behavior
- Orders per customer analysis
- Purchase frequency analysis

## Key Insights

-  Most customers made only one purchase, indicating low retention
-  Card payments dominate (~74%), followed by bank transfers and vouchers
-  Revenue shows steady growth with seasonal fluctuations
-  A small number of product categories generate the majority of revenue
-  Order cancellation rate is very low (<2%)
